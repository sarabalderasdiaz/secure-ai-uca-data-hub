# SECURE AI UCA Data Hub

Material docente de Desarrollo de aplicaciones seguras, organizado por **sesiones de clase**. Sara Balderas Díaz y Gabriel Guerrero Contreras mantienen la autoría de las dos presentaciones finales.

La **sesión 1 fue impartida previamente por Juan Manuel Dodero** y enlaza sus apuntes. Los 20 temas de este paquete se distribuyen inicialmente entre las **sesiones 2 y 8**. El reparto puede ajustarse a la duración de las clases.
