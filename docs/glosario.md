title: "Glosario para seguir las clases"
slug: "/glosario/"
---

| Término | Explicación breve |
|---|---|
| **Ataque / intento** | Acción que busca comprometer un sistema; puede ser bloqueada. |
| **Intrusión** | Acceso o control no autorizado conseguido. |
| **Debilidad** | Tipo de defecto o condición que puede contribuir a una vulnerabilidad. |
| **Vulnerabilidad** | Condición concreta que puede aprovecharse para comprometer la seguridad. |
| **Hallazgo** | Observación de una revisión que requiere valoración y seguimiento. |
| **CWE** | Catálogo de tipos de debilidad. |
| **CVE** | Identificador y registro de una vulnerabilidad concreta divulgada por el programa CVE. Un identificador reservado aún puede no tener detalles públicos. |
| **CVSS** | Sistema de puntuación de severidad técnica; indicar versión y vector. |
| **Autenticación** | Verificar la identidad. |
| **Autorización** | Decidir si esa identidad puede realizar una acción sobre un recurso. |
| **XSS** | Interpretar datos no confiables como código en el navegador de otra persona. |
| **Inyección SQL** | Alterar la estructura o lógica SQL mediante datos incorporados incorrectamente. |
| **Path Traversal** | Acceder fuera de una ubicación autorizada mediante una ruta. |
| **Condición de carrera** | Comportamiento dependiente de cómo se intercalan operaciones concurrentes. |
| **Fail open** | Ante un error, permitir una acción que necesitaba una comprobación. |
| **Log injection / forging** | Inyección de contenido en registros / falsificación de eventos. |
| **SAST / DAST** | Análisis estático / dinámico de seguridad de aplicaciones. |
| **Falso positivo** | Alerta sobre un problema que, en el contexto revisado, no existe. |
| **Falso negativo** | Problema presente que la revisión no detecta. |
| **Regresión** | Reaparición de un fallo o pérdida de comportamiento correcto tras un cambio. |
| **Prueba de regresión** | Comprobación repetible que detecta ese retroceso. |
| **Disponibilidad** | Capacidad de prestar el servicio cuando se necesita. |
| **Fiabilidad** | Operación correcta bajo condiciones y durante un intervalo definidos. |
| **Safety** | Protección frente a daños físicos inaceptables. |
| **Security** | Protección frente a acciones no autorizadas. |
| **Confiabilidad / dependability** | Conjunto de propiedades que permiten confiar en el servicio. |
| **Veracode** | Empresa y plataforma de seguridad de aplicaciones, autora del informe citado. |
| **Interanual** | Comparación con el año anterior. |
| **ReservaLab** | Nombre del escenario ficticio de las primeras diapositivas; no exige instalar una aplicación. |
